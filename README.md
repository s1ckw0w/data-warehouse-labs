# Хранилища данных — лабораторные работы

Репозиторий с материалами лабораторных работ по дисциплине «Хранилища данных».

## Лабораторная работа № 1

- **Вариант № 6:** система составления учебного графика дисциплин факультета.
- **СУБД:** PostgreSQL.
- **Модель:** реляционная схема в третьей нормальной форме (3NF).

- [Описание и порядок выполнения](lab1/README.md)
- [SQL-скрипты](lab1/sql/)
- [ER-модель](lab1/model.md)
- `lab1/report/` — итоговый отчёт в формате DOCX.

### Быстрый запуск

1. Если база `academic_schedule_db` ещё не создана, выполните `lab1/sql/00_create_database.sql` в Query Tool базы `postgres`.
2. Подключитесь к `academic_schedule_db` и выполните `lab1/sql/01_schema_3NF_revised.sql`.
3. Для необязательной проверки добавьте демонстрационные данные скриптом `lab1/sql/02_demo_data_3NF_revised.sql`.
4. Скрипт миграции `03_migrate_existing_schema.sql` нужен только для обновления схемы, созданной предыдущей версией SQL. Не запускайте его на новой базе.

Демонстрационные записи в скрипте — вымышленные.
