# Хранилища данных — лабораторные работы

Материалы лабораторных работ по дисциплине «Хранилища данных».

## Лабораторная работа № 1

- **Вариант № 6:** система составления учебного графика дисциплин факультета.
- **СУБД:** PostgreSQL.
- **Модель:** реляционная схема в третьей нормальной форме (3NF).

### Запуск на новой базе

1. Если база `academic_schedule_db` ещё не создана, выполните `lab1/sql/00_create_database.sql` в Query Tool базы `postgres`.
2. Подключитесь к `academic_schedule_db` и выполните `lab1/sql/01_schema_3NF_revised.sql`.
3. При необходимости добавьте демонстрационные данные скриптом `lab1/sql/02_demo_data_3NF_revised.sql`.
4. `03_migrate_existing_schema.sql` предназначен только для обновления старой схемы; не запускайте его на новой базе.

Демонстрационные записи в скрипте — вымышленные.
