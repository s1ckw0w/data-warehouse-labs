# Лабораторная работа № 1 — вариант 6

**Тема:** система составления учебного графика дисциплин, изучаемых на факультете.  
**Дисциплина:** «Хранилища данных».  
**СУБД:** PostgreSQL.  
**Модель:** третья нормальная форма (3NF).

## Содержимое

- `sql/00_create_database.sql` — создание базы данных `academic_schedule_db`.
- `sql/01_schema_3NF_revised.sql` — создание 14 таблиц, связей, ограничений, индексов, триггера и представлений.
- `sql/02_demo_data_3NF_revised.sql` — необязательные демонстрационные данные.
- `sql/03_migrate_existing_schema.sql` — миграция схемы, созданной старой версией скрипта.
- `../model.md` — ER-модель, которую GitHub отображает как диаграмму.

## Порядок запуска на новой базе

1. В pgAdmin откройте Query Tool базы `postgres`.
2. Выполните `00_create_database.sql` один раз, если `academic_schedule_db` ещё не существует.
3. Подключитесь к `academic_schedule_db`.
4. Выполните весь файл `01_schema_3NF_revised.sql`.
5. При необходимости выполните `02_demo_data_3NF_revised.sql`.
6. Проверьте представления запросами:

```sql
SELECT * FROM v_study_plan_disciplines;
SELECT * FROM v_schedule;
```

## Важно

- Не запускайте `00_create_database.sql`, если база уже существует.
- Не запускайте миграцию `03_migrate_existing_schema.sql` на новой базе. Она предназначена только для обновления старой схемы и рассчитана на пустую таблицу `schedule_entries`.
- Демонстрационные данные вымышлены.
