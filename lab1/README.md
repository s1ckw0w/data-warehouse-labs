# Лабораторная работа № 1 — вариант 6

**Тема:** система составления учебного графика дисциплин, изучаемых на факультете.  
**Дисциплина:** «Хранилища данных».  
**СУБД:** PostgreSQL.  
**Модель:** третья нормальная форма (3NF).

## Файлы комплекта

- `sql/00_create_database.sql` — создание базы данных `academic_schedule_db`.
- `sql/01_schema_3NF_revised.sql` — структура базы, ограничения, индексы, триггер и представления.
- `sql/02_demo_data_3NF_revised.sql` — необязательные демонстрационные данные.
- `sql/03_migrate_existing_schema.sql` — миграция базы, созданной старой версией схемы.
- `model.mmd` — исходный код ER-модели Mermaid.
- `model.md` — ER-модель, отображаемая в Markdown.

## Проверка результата

После создания схемы, а при необходимости и загрузки демонстрационных данных, выполните в Query Tool:

```sql
SELECT * FROM v_study_plan_disciplines;
SELECT * FROM v_schedule;
```

Демонстрационные записи вымышлены. Миграцию не запускайте на новой чистой базе.
